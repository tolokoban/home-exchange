La plupart des déchets vont dans les poubelles sur le parking du cimetière (point **1** sur la carte ci-dessous).

Ce n'est pas obligatoire (mais très apprécié) : vous pouvez faire le tri sélectif si vous le souhaitez.
Pour cela, vous pouvez utiliser les deux caisses noires comme suit :

1. Tout le verre (bouteilles, verres cassés, etc.).
2. Tout le papier, les canettes en aluminium et les plastiques.

![Caisses noires](image/black-boxes.jpg)

Si les caisses sont pleines, vous pouvez les vider dans les poubelles du centre du village (point **2** sur la carte ci-dessous).
