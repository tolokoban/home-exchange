La plupart des déchets vont dans les poubelles sur le parking du cimetière (point **1** sur la carte ci-dessous).

Ce n'est pas obligatoire (mais très apprécié) : vous pouvez faire le tri sélectif si vous le souhaitez.
Pour cela, vous pouvez utiliser les deux caisses noires comme suit :

1. Tout le verre (bouteilles, verres cassés, etc.).
2. Tout le papier, les canettes en aluminium et les plastiques.

![Caisses noires](image/black-boxes.jpg)

Si les caisses sont pleines, vous pouvez les vider dans les containers en bas de la rue, à l'angle du cimetière.

----

Vous pouvez aussi mettre au compost vos épluchures de légumes, par exemple.

1. Un petit récipient se trouve sur la fenête devant le plan de travail.
2. Quand il est plein, vous pouvez le vider dans la boîte noire à gauche en sortant par la porte-fenêtre.
3. Et si cette boîte est pleine, vous pouvez la vider dans le compost du jardin dans l'angle du terrain au dessus du garage.
